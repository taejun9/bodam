# BODAM 제품 정의

## 한 문장

BODAM은 보험설계사 한 명이 고객과 가족의 보험계약·보장·상담·일정을 로컬에서 빠르게 조회하고 관리하는 Windows 우선 개인용 데스크톱 CRM이다.

## 사용자와 환경

- 주 사용자: 보험설계사 1명
- 배포 형태: SaaS가 아닌 개인용 Desktop Application
- 우선 운영체제: Windows
- 연결 조건: 인터넷이 없어도 핵심 기능 전체 사용 가능
- 저장 위치: 사용자 PC의 로컬 SQLite 및 로컬 백업

## 사용자가 빠르게 답해야 하는 질문

- 오늘 연락할 고객은 누구인가?
- 30일, 60일, 90일 안에 만기일이 오는 고객과 승인된 상령 규칙의 대상 고객은 누구인가?
- 고객과 가족이 납입하는 월 보험료는 얼마인가?
- 고객별 보장 합계와 기준 대비 부족·적정·과다는 무엇인가?
- 최근 상담한 고객과 장기간 상담하지 않은 고객은 누구인가?
- 달력의 특정 날짜에 어떤 상담·연락·만기·상령 일정이 있는가?

## 제품 원칙

1. 조회 속도와 마우스 사용성을 시각적 장식보다 우선한다.
2. 날짜·금액·보장 판정은 UI가 아니라 feature service에서 계산한다.
3. 원본 데이터와 계산 결과를 구분하고 계산 기준을 추적 가능하게 한다.
4. Excel/CSV import 오류가 데이터를 조용히 왜곡하지 않도록 검증한다. 검증 preview와 사용자 확인 UX는 별도 계획에서 승인한다.
5. Excel export는 승인된 기준 양식의 헤더·열 순서·형식을 재현한다.
6. 자동 알림·백업은 별도 서버 없이 앱 수명주기 안에서 실행한다.
7. 민감정보를 수집하지 않는 것이 암호화보다 먼저다.

## MVP 범위

1. 프로젝트 생성
2. SQLite 구성
3. 고객 CRUD
4. 가족 관리
5. 보험계약 CRUD
6. 보장 CRUD 및 고객별 합계
7. Dashboard
8. 상담이력
9. 월 Calendar와 사용자 일정
10. Excel/CSV Import
11. Excel/CSV Export
12. 자동 백업과 복원
13. 설정

Calendar는 모든 활성 고객의 상담일·다음 연락일·상령일·만기일과 승인된 사용자 일정을 월별로 제공한다. 사용자 일정은 제목·날짜 필수, 시간·메모·고객 연결 선택, 완료 boolean이며 주·일 보기와 반복·우선순위·drag and drop은 후속 범위다.

## MVP 제외

- Supabase 및 원격 동기화
- PostgreSQL 실운영 전환
- 멀티 사용자와 권한 관리
- 카카오 알림
- 보험 분석 AI
- 보험증권 OCR
- PDF export
- 웹 SaaS, 광고, 분석 추적, 결제

## 성공 기준

- 인터넷을 끊은 상태에서 고객·가족·계약·보장·상담·달력·대시보드·백업을 사용할 수 있다.
- 상령·만기·다음 연락 대상이 동일한 기준일에서 재현 가능하게 계산된다.
- 고객과 가족 단위 보험료 및 보장 합계가 원본 계약/보장 데이터와 대사된다.
- 첨부 기준과 동일한 계약조회 Excel 양식을 import하고 같은 열 계약으로 export할 수 있다.
- 금지된 민감정보가 입력 경계, 샘플, 로그, 백업 설명에 포함되지 않는다.
