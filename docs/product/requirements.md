# 제품 요구사항

이 문서는 사용자가 명시한 범위만 정리한다. 필드의 enum, 계산식, 중복 판정처럼 확정되지 않은 내용은 open-questions.md에 둔다.

## Customer

- 이름
- 생년월일
- 성별
- 연락처
- 주소
- 메모
- 담당상태
- 삭제 시 deletedAt을 기록하고 기본 조회에서 제외

## Family

- 가족 단위 관리
- 가족 구성원 조회
- 구성원 보험료 합산

가족 관계 명칭과 한 고객의 복수 가족 소속 가능 여부는 미정이다.

## Insurance

- 보험사
- 상품명
- 가입일
- 보험기간
- 납입기간
- 월 보험료
- 고지플랜
- 만기일
- 갱신 여부
- 고객과의 Foreign Key
- 삭제 시 deletedAt을 기록

## Coverage

모든 보장을 표준 카테고리에 연결하고 고객별 보장금액을 합산한다.

초기 예시 카테고리:

- 암
- 유사암
- 뇌혈관
- 심혈관
- 질병수술
- 상해수술
- 후유장해
- 입원
- 간병
- 운전자

예시는 초기 데이터 후보이며 승인 없이 고정 enum으로 만들지 않는다.

## Coverage Benchmark

- 연령대
- 성별
- 카테고리
- 기준금액
- 부족
- 적정
- 과다
- 초기 버전에서 사용자가 수정 가능

판정 구간의 경계 포함 규칙과 중복 기준 적용 우선순위는 미정이다.

## Consultation

- 상담일
- 상담내용
- 다음 연락일
- 상담 결과
- 고객과의 Foreign Key
- 삭제 시 deletedAt을 기록

상담 메모에도 민감 병력과 상세 병력을 저장하지 않는다.

## Dashboard

- 오늘 연락해야 하는 고객
- 상령 예정
- 만기 예정
- 보험료 TOP
- 가족 보험료
- 보장 부족 고객
- 최근 상담 고객
- 최근 미상담 고객

각 카드의 기간, 정렬, 건수, 동점 규칙은 계획에서 승인받는다.

## Calendar

- 날짜별 상담일, 다음 연락일, 상령일, 만기일을 조회
- 사용자 일정 표시
- 로컬 시간대를 사용하며 서버 동기화는 하지 않음

월·주·일 보기, 일정 생성 필드, 날짜 선택 동작과 관련 화면 이동은 아직 확정하지 않는다.

## Notification

- 프로그램 시작 시 로컬 데이터로 자동 계산
- 30일, 60일, 90일 만기 대상
- 상령일 대상
- 별도 서버 없음

## Import / Export

- Excel import/export
- CSV import/export
- 첨부 계약조회 양식의 열 계약과 표시 형식 지원
- 행 단위 검증, 오류 표시와 반영 확인 UX는 구현 계획에서 승인
- PDF export는 MVP 제외

## Backup

- 프로그램 종료 시 백업
- 하루 1회 자동 백업
- 최근 30개 보관
- 복원 기능

백업 중복 실행, 실패 복구, 암호화 여부와 저장 경로는 별도 계획에서 확정한다.

## UI

- Windows 프로그램 느낌의 단순한 디자인
- 다크모드
- 반응속도 우선
- 마우스 사용성 우선
